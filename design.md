## Brand & Style

This design system expresses high-assurance defense, cryptographic precision, and operational intelligence for mission-critical enterprise environments. The aesthetic marries technical minimalism with high-end tactical telemetry: deep obsidian substrates, razor-sharp containment borders, micro-glow states, and laser-focused optical contrast.

The target demographic consists of Chief Information Security Officers, DevSecOps directors, red-team operators, and AI governance architects who demand high-density data legibility, low latency perception, and definitive visual states without visual gimmickry.

Key design attributes:
- **Technical Precision:** Zero-bloat layouts, rigid geometric alignment, monospaced computational verification anchors, and strict 1px boundary lines.
- **Controlled Luminescence:** Ambient black voids paired with selective, high-frequency electric lime and emerald green emitters signaling active operational security, threat containment, and runtime verification.
- **Tactical Translucency:** Dark charcoal glassmorphism engineered with hardware-accelerated backdrops to preserve context layers across deep inspection trees.

## Colors

The palette establishes an ultra-low-reflection operations cockpit using deep obsidian blacks, punctuated strictly by high-energy emerald and electric lime photons.

### Surface Architecture
- **Base Canvas (`#08090A`):** The absolute foundational background. Absorbs screen fatigue during prolonged threat-monitoring sessions.
- **Surface Elevation 1 (`#0D0F12`):** Structural panels, sidebars, and nested data docks.
- **Glass Matrix (`rgba(18, 22, 28, 0.70)`):** Contextual overlays, flyout telemetry windows, and elevated security cards; paired with `backdrop-filter: blur(16px)`.

### Signal & Threat Indicators
- **Primary / Active Intercept (`#00FF87`):** Represents optimal runtime posture, verified AI token validation, and primary interaction triggers.
- **Secondary / Steady State (`#10B981`):** Passive active services, baseline firewalls, and policy compliance verification.
- **Tertiary / Elevated Telemetry (`#A3E635`):** Algorithmic anomaly flags, sandbox testing runs, and real-time inference tracing.
- **Border Ghost Substrate (`rgba(255, 255, 255, 0.08)`):** Base structural boundary for cards, tables, and compartmentalized frames.
- **Active Containment Perimeter (`rgba(74, 222, 128, 0.25)`):** State-focused line indicator for highlighted threats, hovered cards, and active terminal inputs.

### Text & Telemetry Contrast
- **Primary Text (`#FFFFFF`):** High-impact headlines, threat counts, and cryptographic IDs.
- **Secondary Steel (`#94A3B8`):** System labels, column descriptions, and audit timestamps.
- **Muted Carbon (`#475569`):** Inactive indicators, non-essential telemetry units, and disabled trigger boundaries.

## Typography

The typographic stack balances cold computational efficiency with executive clarity.

- **Display & Headings (Space Grotesk):** Engineered for geometric impact and technological edge. Used for threat metrics, platform modules, and high-level analytical dashboards. Tight negative letter-spacing reinforces structural rigidity.
- **Body & Prose (Geist):** Clean, highly legible neutral workhorse. Delivers fatigue-free scanning across dense compliance frameworks, model provenance logs, and incident timelines.
- **System Labels, Monospace Telemetry, & Token Streams (JetBrains Mono):** Applied to model weights, SHA-256 hashes, neural latency counters, status tags, and payload previews. The expanded letter-spacing on `label-sm` optimizes micro-data legibility on dark glass backgrounds.

## Layout & Spacing

The layout philosophy uses a disciplined 12-column fluid grid system pinned inside a max-width cockpit of `1600px` for operations dashboards, with fluid full-bleed expansion for interactive neural topology maps.

### Rhythm & Proportions
- **Sub-grid Unit:** 4px baseline grid. All spatial offsets, component heights, and line-heights are multiples of 4px.
- **Component Packaging:** Compact, high-information density. Component interiors use `space-xs` and `space-sm` for metric-label relationships, and `space-md` for standard card container padding.
- **Section Intervals:** Major containment modules separate by `space-lg` (24px) or `space-xl` (32px) to clearly isolate divergent threat matrices.

### Responsiveness & Adaptability
- **Desktop (1280px+):** 12 columns, 24px gutters (`gutter-desktop`), 40px outer margins (`margin-desktop`). Tri-panel views active (Audit Explorer, Live Trace Graph, Inspector Sheet).
- **Tablet (768px – 1279px):** 8 columns, 16px gutters, 24px outer margins (`margin-tablet`). Secondary inspector sheets collapse into drawer overlays.
- **Mobile (Below 768px):** 4 columns, 16px gutters, 16px outer margins (`margin`). Single-stream analytical stack with sticky horizontal tab pivots.

## Elevation & Depth

Visual hierarchy does not rely on traditional muddy drop shadows; instead, it uses luminous edge diffraction, translucent obsidian glass, and optical glow signatures.

### Layering Architecture
- **Base Ground (`z-index: 0`):** Solid `#08090A` surface.
- **Flat Glass Docks (`z-index: 10`):** `background: rgba(18, 22, 28, 0.70)`, `backdrop-filter: blur(16px)`, `border: 1px solid rgba(255, 255, 255, 0.08)`.
- **Raised Critical Panels (`z-index: 20`):** Background elevated to `rgba(26, 32, 40, 0.85)` with perimeter light: `box-shadow: 0 0 0 1px rgba(74, 222, 128, 0.20), 0 12px 32px rgba(0, 0, 0, 0.60)`.
- **Floating Overlays & Command Modals (`z-index: 50`):** `background: #0D0F12`, `border: 1px solid rgba(0, 255, 135, 0.35)`, `box-shadow: 0 0 30px rgba(0, 255, 135, 0.10), 0 24px 48px rgba(0, 0, 0, 0.85)`.

### Optical Glow States
Hovering over interactive elements initiates an ambient phosphor bleed: an ultra-subtle green radial gradient centered at the interaction origin, combined with a `box-shadow: inset 0 0 12px rgba(0, 255, 135, 0.05)`.

## Shapes

The design system employs a restrained, tactical geometric shape language (`roundedness: 1`). Soft 4px (`0.25rem`) standard radiuses establish clean, sharp engineering discipline across cards, inputs, and containment borders, rejecting frivolous curves.

- **Base Components (Inputs, Buttons, Badges):** 4px border radius (`0.25rem`).
- **Containers & Glass Panels (`rounded-lg`):** 8px border radius (`0.5rem`).
- **Command Overlays & Modals (`rounded-xl`):** 12px border radius (`0.75rem`).
- **Telemetry Indicators & Pinhole Status Nodes:** 9999px (circular/pill) exclusively reserved for live pulsating telemetry dots and standalone micro-pills.

## Components

### Buttons
- **Primary Cyber-Action:** Background `#00FF87` with text `#08090A` in `JetBrains Mono` font weight 600. Border: 1px solid `#00FF87`. Hover triggers an emerald halo: `box-shadow: 0 0 18px rgba(0, 255, 135, 0.40)`.
- **Secondary Ghost:** Background `rgba(18, 22, 28, 0.80)`, text `#FFFFFF`, border `1px solid rgba(255, 255, 255, 0.12)`. Hover updates border to `rgba(74, 222, 128, 0.50)` with text `#00FF87`.
- **Critical / Intercept:** Background `rgba(239, 68, 68, 0.10)`, text `#F87171`, border `1px solid rgba(239, 68, 68, 0.30)`. Hover shifts to full crimson saturation.

### Chips & Badges
- Constructed with `label-sm` uppercase JetBrains Mono typography. Height locked to 22px.
- **Secure Model Badge:** Background `rgba(16, 185, 129, 0.12)`, text `#4ADE80`, border `1px solid rgba(74, 222, 128, 0.25)`. Prepended with an emerald 4px pulsing dot.
- **Policy In-Review:** Background `rgba(163, 230, 53, 0.10)`, text `#A3E635`, border `1px solid rgba(163, 230, 53, 0.20)`.

### Cards & Analytical Panels
- Structural glass enclosure: `rgba(18, 22, 28, 0.70)` surface fill, 16px backdrop blur, 1px perimeter border of `rgba(255, 255, 255, 0.08)`.
- Headers feature integrated micro-telemetry rails: a 1px bottom divider line `rgba(255, 255, 255, 0.06)` with title aligned left in `Space Grotesk` and real-time status telemetry aligned right in `JetBrains Mono`.

### Data Tables & Event Feeds
- Zebra-free styling. Row lines demarcated solely by 1px borders in `rgba(255, 255, 255, 0.04)`.
- Row hover triggers high-contrast surface illumination: `background: rgba(255, 255, 255, 0.02)` and a left border flash of 2px `#00FF87`.
- Column headers set in `JetBrains Mono` `label-md` with muted steel gray `#94A3B8`.

### Input Fields & Terminal Prompts
- Dark recessed background `#08090A`, border `1px solid rgba(255, 255, 255, 0.12)`, inner padding `0.5rem 0.75rem`.
- Text displayed in `Geist` or `JetBrains Mono` at `#FFFFFF` with placeholder text in `#475569`.
- Focused state: border instantly shifts to `#00FF87`, backed by `box-shadow: 0 0 10px rgba(0, 255, 135, 0.15)`.

### Checkboxes & Binary Toggles
- **Checkbox:** 16x16px container, 2px radius, border `1px solid rgba(255, 255, 255, 0.20)`. Checked state fills with `#00FF87`, border `#00FF87`, with an obsidian checkmark icon.
- **Switch / Toggle:** 36x20px capsule track in `#0D0F12` with 1px border `rgba(255, 255, 255, 0.15)`. Active state fills track with `rgba(0, 255, 135, 0.20)` and slides the thumb (#00FF87) with an emerald micro-glow.

### Security-Specific Components
- **Model Drift Radar:** Circular canvas container enclosed in faint range rings (`rgba(255, 255, 255, 0.06)`) with high-contrast `#00FF87` anomaly vectors.
- **Cryptographic Hash Pill:** Compact monospaced string displaying truncated SHA keys with a click-to-copy trigger that flashes electric green confirmation upon clipboard write.
